# soundKit_MT
Sound modding kit (SDKT) for Marvel Tokon

OVERVIEW
--------------------------------------------------------------

(GRAB AN FMODEL DOWNLOAD FROM HERE: https://fmodel.app/download)

1. ~~Written instructions are included~~

2. SDKT (Soundkit Modding Tool) is for:
   
   - Extracting and organizing most (playable, for now) character voices from Marvel Tokon

   - Extracting and organizing most, if not all, character voice subtitles from the game

   - Replacing ingame audio files with your custom files

   - Other, miscellaneous operations
   
   Character ID List can be found [here](<https://docs.google.com/spreadsheets/d/160YQ4scnSduVM6c7Ce1DDw9uAFpLKdaGdpatLZzrAT0/edit?gid=0#gid=0>)
