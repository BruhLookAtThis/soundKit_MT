UPDATE 0.1.1 (08-21-2026) (NOT RELEASED YET, `BUG TESTING`)
### 

### For General
## IMPORTANT
- If you setup soundKit_MT v0.1.0 already, follow these steps
  - Clear out your `soundKit_MT\1-RENAMED-Media-Wems-Here`, `soundKit_MT\0_DATA\0-MEDIA`, and `soundKit_MT\\0_DATA\0-JSONS` folders before proceeding
  - Extract `MTFS\Content\Chara` as json (this WILL take a bit). Place the extracted `Chara` folder into `soundKit_MT\0_DATA\0-JSONS`
    - As stated, this WILL take quite a while, maybe like 5-15 minutes
    - If you just want to instead just grab a specific character go to this path: `MTFS/Content/Chara/<CHARA_ID>/Common/Audio`
    - Extract that `Audio` folder as json. Place the extracted `Chara` folder into `soundKit_MT\0_DATA\0-JSONS`
  - Extract `MTFS\Content\LocalizeText` as json. Place the extracted `LocalizeText` folder into `soundKit_MT\0_DATA\0-JSONS`
  - Extract `MTFS\Content\Audio\BGM` as json. Place the extracted `Audio` folder into `soundKit_MT\0_DATA\0-JSONS`
  - Extract `MTFS\Content\Audio\Lobby` as json. Place the extracted `Audio` folder into `soundKit_MT\0_DATA\0-JSONS`
  - Extract `MTFS\Content\Audio\Media` as audio (this may take a bit). Place the extracted `Audio` folder into `soundKit_MT\0_DATA\0-MEDIA`
  - Extract `MTFS\Content\Audio\Narration` as json. Place the extracted `Audio` folder into `soundKit_MT\0_DATA\0-JSONS`
  - Extract `MTFS\Content\Audio\OptionMenu` as json. Place the extracted `Audio` folder into `soundKit_MT\0_DATA\0-JSONS`
  - Extract `MTFS\Content\Audio\Ringcall` as json. Place the extracted `Audio` folder into `soundKit_MT\0_DATA\0-JSONS`
  - Extract `MTFS\Content\Audio\StartupBattle` as json. Place the extracted `Audio` folder into `soundKit_MT\0_DATA\0-JSONS`

- Updated the `0-CHARACTER-ID-LIST.txt` file
- Changed `ESB: CHARA - Champion (ESB)` to `ESB: CHARA - Champion (Battle) (ESB)` in the `0-CHARACTER-ID-LIST.txt` file

### For SDKT
- Added auto-sorting of eligible .wem files in `1-RENAMED-Media-Wems-Here\zzz_UNSORTED` based on updated data in `\0_DATA\0-TXTs\0-CHARACTER-ID-LIST.txt` to script startup
  - For Example: If `en-US\UNSORTED(VO)-vesn000a-761983099.wem` is in your `zzz_UNSORTED` folder
  - And you recently added `ESN: CHARA - Champion (Normal) (ESN)` to the `0-CHARACTER-ID-LIST.txt` file
  - When you start the script, it will automatically organize that `UNSORTED(VO)-vesn000a-761983099.wem` file into `CHARA - Champion (Normal) (ESN)` (by default)
  - NOTE: This requires a fresh Option 1 run if you are coming from `soundKit_MT v0.1.0`
  
- Added far more files to Option 1 sorting algorithm
  - Option 1 can now sort Sound Effects, Music, and additional character voices (Ringcalls, Narrators, etc)
    - NOTE: Modding Music is still a mess, as far as I am concerned
    - This script will organize the music files for you, but from there, its uncharted territory
    - I personally avoid modding in Unreal Engine games because I have never had a smooth experience with that
    - I also listen to Spotify when I game, so I have almost zero interest in modding music anyway
  - Voice .wems will now have `(VO)` added to their filenames
  - Sound Effect .wems will now have `(SE)` added to their filenames
  - Music .wems will now have `(BGM)` added to their filenames
  
- Added Option 102
  - This option allows users to search all jsons for wem IDs or text strings
  - Jsons that contain an exact match will be copied into a folder named after their searched term within `\x100-XTRAs-Are-Here\x102-SEARCHED-Wem-Stuff`
    - For Example: If you searched `17625637`, your resulting jsons, if any, will be output to `\x100-XTRAs-Are-Here\x102-SEARCHED-Wem-Stuff\17625637\`
  - If multiple copies of a json contain your searched term, each duplicate will have `(<#>)` attached to its name to avoid overlapping/overwriting
  - This Option is mainly for research purposes, the average user shouldnt need to use this option
  
- Adjusted the `WEM-ID-CHART.txt` file generated by Option 1 to include file paths too
  - This in turn should speed up processing for Option 2
